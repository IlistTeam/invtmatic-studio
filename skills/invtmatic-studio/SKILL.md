# INVTmatic Studio

Для настройки или недоступного MCP прочитай [установку плагина](../../docs/PLUGIN.md).
Перед разработкой прочитай [основной навык](../../SKILL.md). Его ссылки и пути
разрешаются от корня пакета, на два уровня выше этого файла; ресурсы не нужно копировать.

Используй сервер `invtmatic-persistent`, подключённый плагином. Сначала вызови
`invt_session_status`; установка и инициализация не запускают Studio.
Стандартная конфигурация плагина не включает физические операции TM751.
Не создавай второй MCP поверх существующей регистрации того же сервера.
Проекты и результаты храни в выбранной рабочей папке вне кэша плагина.
